# Acceptance Audit Findings for Story 8.3

- **Missing Codebase Implementation (Incomplete Diff)**: Violates AC1, AC2, AC6, AC7, AC8 and all ATDD requirements. The provided diff only contains a subset of the backend implementation (entity, repository, generator, and lifecycle service classes). Critical components required by the spec and explicitly listed in the task list are missing entirely, including `TournamentScheduler`, `TournamentController`, DTOs, Event/Listener classes, all Frontend UI components (`TournamentBracket.vue`, etc.), and all testing artifacts.
- **Deviation from Spec Intent on Zero-Match Seeding**: Violates FR43 / Dev Notes constraints. In `StrengthBasedSeedingStrategy.java`, zero-match participants and participants with match history but zero wins both evaluate to a `strengthScore` of 0.0 and `totalWins` of 0. This results in them being tied and sorted identically by `createdAt`, directly violating the spec constraint: *"Zero-match participants are seeded below participants with match history, sorted by registration timestamp."* The `ParticipantStats` record needs to capture `totalMatches` or a `hasMatchHistory` flag to enforce this precedence.
- **Missing Implementation Detail (JPA Transient Persistence Bug)**: Violates Implementation Guardrails. In `TournamentMatch.java`, the `nextMatch` self-referencing relationship lacks `CascadeType.PERSIST` or `CascadeType.MERGE`. Because `CupBracketGenerator` generates and returns matches ordered from Round 1 to Round $N$, saving the list sequentially via `tournamentMatchRepository.saveAll(matches)` will immediately throw a `TransientPropertyValueException` as Round 1 matches reference unsaved, transient Round 2 matches (which do not yet have assigned UUIDs).
- **Missing Implementation of Push Notifications**: Violates AC2, AC6, and FR55. The `TournamentLifecycleServiceImpl` correctly publishes `TournamentCancelledEvent` and `TournamentStartedEvent`. However, because the `TournamentNotificationListener` and `PushNotificationService` updates are missing from the diff, the required push notifications triggered by these events will not be sent to the participants.
